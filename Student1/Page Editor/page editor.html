Splash Page

Technical Description

I designed the splash page with a dynamic background animation using CSS keyframes ('weatherShift') to create a shifting effect. The page uses semantic HTML for structure and includes a redirect to the home page after 4 seconds using a meta refresh tag. I also implemented a pulsing logo animation with the 'logoPulse' keyframe to enhance visual appeal.

Accessibility

I ensured accessibility by using high-contrast text (white on a dark overlay) and text shadows for readability. The page includes alt text for the logo image and uses Google Fonts (Bebas Neue, Montserrat, Open Sans) for consistent typography across devices.

Volunteer Page

Technical Description

I developed the volunteer page with a responsive carousel using JavaScript to cycle through images every 5 seconds, with clickable dots for manual navigation. The page features a grid of volunteer cards styled with CSS Grid, adjusting from 4 columns on desktop to 1 on mobile using media queries.

Accessibility

I added alt text to all images in the carousel and volunteer cards for screen readers. The navigation menu includes a mobile toggle button, ensuring usability on smaller screens. Hover effects on buttons and cards use transitions for visual feedback without disrupting accessibility.

Content Page

Technical Description

I structured the content page using div containers for each section, styled with CSS to include background images and overlays for visual depth. The page includes a single volunteer card at the bottom, reusing the card styling from the volunteer page, and features a consistent navbar and footer across the site.

Accessibility

I implemented a scroll-to-top button that appears after scrolling 300px, improving navigation on long content. Images include alt text, and text is styled with sufficient contrast against backgrounds. The layout uses flexbox for centered alignment, ensuring responsiveness across devices.

Challenges and Lessons Learned

Initially, I struggled with CSS and JavaScript, especially animations and responsive design. This coursework was challenging with only 45 days, but I learned to implement carousels, keyframes, and media queries. Positioning elements was tricky—I used 'justify-content' and 'align-items' to center content. Sourcing free images was tough due to watermarks, so I relied on Unsplash for high-quality assets.

Compliance

I adhered to JANET regulations for educational web content, focusing on ethical use and copyright compliance. Images from Unsplash are credited appropriately, and I avoided using copyrighted material without permission, referencing sources where applicable.

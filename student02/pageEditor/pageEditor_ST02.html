Content Page

Technical Description

I structured the webpage by using (div) tags to separate each section, ensuring a clear and modular layout for content like the header, main body, and footer. Each (div) acts as a container, isolating distinct parts of the page—such as the about section or contact area—making it easier to apply unique styling with CSS, like background colors, padding, or borders. This method keeps the code organized and maintainable, allowing me to target specific sections for adjustments without affecting others. By pairing these (div) tags with meaningful class or ID names, I created a flexible foundation that enhances both design consistency and functionality across the site.

Accessibility

I developed a navigation system to connect each section of the webpage by writing code that utilizes unordered list (ul) tags for a clean and structured layout. In HTML, I created an unordered list within a navigation bar, with each (li) element linking to a corresponding section using anchor tags and unique IDs—like #about or #contact. I styled it with CSS to align the list items horizontally, adding hover effects and spacing for a polished look.
